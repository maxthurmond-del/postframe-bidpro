# PostFrame BidPro

Post-frame construction estimating, takeoff, proposal, and building-preview PWA.

## Live deployment

This repository includes a GitHub Actions workflow that deploys the app to GitHub Pages whenever the `main` branch changes.

See [GITHUB-SETUP.md](GITHUB-SETUP.md) for upload, publishing, installation, and update instructions.

## Important

This is an estimating tool. Structural design, quantities, engineering, site loads, code requirements, taxes, and final contract terms must be independently verified.
